# Security

MinePointer posts mouse events, reads keyboard events through an event tap for its hotkeys, and runs AirPointer's helper, which talks to the AirPods over private Bluetooth APIs. Please report anything that could let another process or a nearby device abuse these.

Report a vulnerability privately through [GitHub's security advisories](https://github.com/rymqan/MinePointer/security/advisories/new) rather than a public issue. Issues in AirPointer's own code belong upstream at https://github.com/oscarcreatess/airpointer.
